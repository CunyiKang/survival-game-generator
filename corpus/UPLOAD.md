# 语料库上传说明

> 未来模块：上传精神疾病问卷量表、专业书籍、网络资料，用于 AI 自动生成符合特定主题的题目。

## 计划支持的文件格式

| 类型 | 格式 | 说明 |
|------|------|------|
| 问卷量表 | .pdf / .docx / .txt | PHQ-9、BDI、MADRS 等标准化量表 |
| 专业书籍 | .pdf / .epub | DSM-5、ICD-11、临床心理学教材等 |
| 网络资料 | .txt / .md / .html | 网上爬取的病例讨论、治疗经验等 |
| 自定义题目 | .json / .csv | 直接上传题目数据 |

## 上传流程（规划中）

```bash
# 1. 将文件放入 corpus/input/ 目录
mkdir corpus/input
# 放入你的量表 PDF 或书籍

# 2. 运行解析脚本
node corpus/parser.js

# 3. AI 自动解析并提取关键维度
# 系统会自动：
#   - 识别量表维度（如"抑郁情绪""睡眠障碍""自我评价"）
#   - 匹配到游戏的5个属性体系
#   - 生成针对性的情境题库

# 4. 导出生成的游戏配置
node corpus/export.js --theme depression
```

## 文件命名规范

```
corpus/
├── input/
│   ├── phq9_cn.pdf          # 标准化量表（建议附上中文版本）
│   ├── dsm5_chapter8.txt    # 专业书籍章节
│   └── patient_forum.txt    # 网络论坛讨论（脱敏后）
├── parsed/                   # AI 解析后的中间结果
└── output/                  # 导出的游戏配置
    └── depression/
        └── scenarios/
```

## 注意事项

- **隐私脱敏**：上传的网络资料必须经过脱敏处理，不得包含真实患者姓名、联系方式等个人信息
- **版权说明**：请确保你有权使用上传的书籍和资料内容
- **内容分级**：系统会自动识别内容的受众年龄范围，避免引入不适宜青少年的内容
